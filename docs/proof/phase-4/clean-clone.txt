Ba lệnh người dùng theo README:
  1. git clone <repo> chonoi
  2. cd chonoi
  3. python3 -m chonoi.live --mode gather

Kiểm tra tự động trên clone tạm:
  - `git clone --no-local --depth 1 . <temp>` thành công.
  - Khởi động `python -m chonoi.live --mode gather --port <free-port>`.
  - GET /state trả HTTP 200.
  - `git status --porcelain` trong clone rỗng.
